# Nayi Manzil Landing Page

A simple and modern landing page for the Nayi Manzil, built with plain HTML and CSS.

## Project Overview
This project presents a professional home page with:
-a hero section
- an about section
- service cards
- a contact form
- a footer with social links

## Files
- `index.html` — page structure and content
- `style.css` — styling, layout, and responsive design

## How to Run
You can preview the site by opening `index.html` in a browser.



## Customization
You can update the text, colors, and images directly in the HTML and CSS files to match your brand or business requirements.
